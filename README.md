# 1.44game

2P GAME ARCADE 「1.44MB GAME_DEV CONTEST」 출품작 프로젝트.
전체 배포 패키지(실행파일+에셋)를 1,474,560 bytes(1.44MB) 이하로 유지하는 것이 목표.

K9 자주포 수동 사격 절차를 모티브로 한 밀(Mil) 단위 방열 게임. 전장은 안 보이고
포반원 시점에서 하달받은 방위각/사각 수치에 맞춰 빠르고 정확하게 방열하는 게임.

- 마감: 2026-09-04 23:59 (KST)
- 규칙: 인터넷/서버 없이 독립 실행되는 실행파일이어야 함 (웹 게임 불가)

**게임 디자인/의사결정 배경은 [`CONTEXT.md`](./CONTEXT.md) 참고** — 왜 이 구조가
됐는지, 뭘 시도했다 버렸는지, 다음에 뭘 해야 하는지 정리되어 있음.

## 구조

- `src/main.c` — 순수 Win32 API + GDI 소프트웨어 렌더링 기반 게임 전체 (외부 런타임 의존성 없음)
- `build.sh` — mingw-w64로 Windows용 실행파일을 크기 최적화 빌드
- `check_size.sh` — 빌드 결과물이 1.44MB 제한 내에 있는지 검사

## 빌드 방법

```sh
./build.sh          # dist/game.exe 생성
./check_size.sh      # 용량 확인
```

Windows에서 실행하려면 `dist/game.exe`를 그대로 복사해서 더블클릭.
Linux 환경에서는 Wine으로 테스트 가능: `wine dist/game.exe`

크로스컴파일에 mingw-w64가 필요함 (`apt install mingw-w64` 등).

## 조작

- **로비**: 마우스로 START/OPTIONS/EXIT 클릭
- **인트로**: Space, 클릭, 또는 ESC로 스킵
- **조작화면(방위각)**: 좌클릭 드래그로 회전(러프), 우클릭으로 미세조정(1밀),
  스페이스로 확정
- **조작화면(사각)**: 좌클릭 드래그로 스크롤(관성 있음), 우클릭으로 미세조정(1밀),
  스페이스로 확정
- ESC: 조작화면에서는 로비로 나가기
