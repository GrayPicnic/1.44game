# 1.44game

2P GAME ARCADE 「1.44MB GAME_DEV CONTEST」 출품작 프로젝트.
전체 배포 패키지(실행파일+에셋)를 1,474,560 bytes(1.44MB) 이하로 유지하는 것이 목표.

K9 자주포 수동 사격 절차를 모티브로 한 밀(Mil) 단위 방열 게임. 전장은 안 보이고
포반원 시점에서 하달받은 방위각/사각 수치에 맞춰 빠르고 정확하게 방열하는 게임.

- 마감: 2026-09-04 23:59 (KST)
- 규칙: 인터넷/서버 없이 독립 실행되는 실행파일이어야 함 (웹 게임 불가)

**게임 디자인/의사결정 배경은 [`CONTEXT.md`](./CONTEXT.md) 참고** — 왜 이 구조가
됐는지, 뭘 시도했다 버렸는지, 다음에 뭘 해야 하는지 정리되어 있음.

## 구조

- `src/main.c` — 순수 Win32 API + GDI 소프트웨어 렌더링 기반 게임 전체 (외부 런타임 의존성 없음)
- `images/` — 배경 아트 원본(BMP, 8비트 인덱스 또는 24비트). `build.sh`가
  `dist/images/`로 같이 복사하고, 실행 시 exe 옆 `images/`에서 읽음.
  640x360(`GAME_W x GAME_H`) 크기가 아니면 로드가 실패하고 기존 단색
  placeholder로 자동 폴백함.
- `build.sh` — mingw-w64로 Windows용 실행파일을 크기 최적화 빌드
- `check_size.sh` — 빌드 결과물이 1.44MB 제한 내에 있는지 검사

## 빌드 방법

```sh
./build.sh          # dist/game.exe 생성
./check_size.sh      # 용량 확인
```

Windows에서 실행하려면 `dist/game.exe`를 그대로 복사해서 더블클릭.
Linux 환경에서는 Wine으로 테스트 가능: `wine dist/game.exe`

크로스컴파일에 mingw-w64가 필요함 (`apt install mingw-w64` 등).
Windows에서 직접 빌드하려면 [MSYS2](https://www.msys2.org/) 설치 후
`pacman -S mingw-w64-x86_64-gcc zip`으로 동일한 툴체인을 맞추면 같은
`build.sh`/`check_size.sh`가 그대로 동작함(별도 스크립트 불필요).

## 조작

- **로비**: 아무 키나 누르거나 화면(톱니바퀴 제외) 클릭으로 시작, 우상단
  톱니바퀴 아이콘 클릭으로 옵션, ESC로 게임 종료
- **인트로**: Space 또는 클릭으로 스킵 (ESC는 인트로에서 동작하지 않음)
- **1단계(방위각)**: 좌클릭 드래그로 회전(러프), 우클릭으로 미세조정(1밀),
  스페이스로 확정
- **2단계(사각)**: 좌클릭 드래그로 스크롤(관성 있음), 우클릭으로 미세조정(1밀),
  스페이스로 확정
- **3단계(사격)**: 게이지 위 불릿이 붉은 표시와 겹치는 순간 좌클릭으로 발사,
  5회 명중 시 클리어 (실패 시 바로 게임오버)
- **4단계(장약)**: 무더기의 원반을 드래그로 치우며 무전으로 불러준 번호를 찾아
  통에 드롭 — 통 안 원반들의 합이 목표와 같으면 됨(하나로 맞춰도, 여러 개를
  더해도 OK)
- ESC: 조작화면에서는 로비로 나가기
